# Readme— Yara Nascimento

A single-page, responsive HTML/CSS resume/portfolio site.

## Preview

Open `index.html` in any browser — no build step or dependencies required.

## Structure

- **Header** — name, title, and links (LinkedIn, GitHub, Email)
- **Sidebar** — contact info, technical skills, languages
- **Main content** — about, projects, education
- **Footer** — social links and site info
- **Back-to-top button** — fixed, appears on scroll

## Tech

- Plain HTML5 + CSS3 (no frameworks, no JS)
- Google Fonts: [Fraunces](https://fonts.google.com/specimen/Fraunces) (headings) + [Inter](https://fonts.google.com/specimen/Inter) (body)
- CSS Grid for layout, CSS custom properties for the color palette
- Fully responsive (single-column layout below 768px)

## Customize

- **Colors** — edit the variables in `:root` at the top of the `<style>` block
- **Photo** — replace the `.photo` div's background with an `<img>` tag
- **Content** — edit text directly in the HTML (contact info, skills, projects, education)
- **Links** — update the `href="#"` placeholders (LinkedIn, GitHub, social icons) with real URLs
